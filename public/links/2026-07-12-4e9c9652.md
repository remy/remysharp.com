# This was the first commit via an LLM to git

TIL: git (the command line tool) now contains LLM generated code (I'm still unsure, we're calling this generative AI, right?). Landed in Jan 2026.

I appreciate there's some folks out there that don't want to touch LLM generated content or have it in your tool chains, I'm just going to assume that's going to be very hard as time goes on.

Though I do also appreciate there are projects working thanklessly to achieve [just that](https://git-annex.branchable.com/no_llm_code/).
